# Optional civic-building models

Put CC0 low-poly `.glb` files here (for example from Kenney.nl) and map civic-building kinds to them in
`manifest.json` next to this file, e.g.

```json
{ "library": "library.glb", "statue": "statue.glb" }
```

Kinds: library, lighthouse, observatory, garden, statue, landmark.
Models should fit a 3×3-unit cell with their origin at the base centre. Unlisted kinds use the built-in shapes.
