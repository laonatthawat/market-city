# Market City 🏙️

เกมสามมิติสำหรับเรียนรู้การลงทุน บริษัทแต่ละแห่งในตลาดคือตึกหนึ่งหลังในเมือง low-poly และเกมจะเล่นย้อนตามข้อมูลตลาดจริงในอดีต (ไม่ใช่ข้อมูลเรียลไทม์)

## เริ่มใช้งาน

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests ของ engine
npm run build
```

ถ้ายังไม่ได้รันสคริปต์ดึงข้อมูล เกมจะสลับไปใช้ **ตลาดจำลอง** (SimulatedProvider, seed คงที่) ให้เอง จึงเล่นได้ทันที

## ดึงข้อมูลย้อนหลังจริง (Python + yfinance)

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows  (macOS/Linux: source .venv/bin/activate)
pip install -r scripts/requirements.txt
python scripts/fetch_data.py                   # หุ้นทั้งหมด ~98 ตัว ใช้เวลาหลายนาที
python scripts/fetch_data.py --only AAPL,MSFT  # ทดสอบเร็ว ๆ
```

ไฟล์ที่ได้จะอยู่ใน `public/data/`
- `manifest.json` เก็บปฏิทินวันทำการ ข้อมูลบริษัท งบการเงินรายปี (ค่าประมาณ) และวันประกาศงบ
- `prices/<TICKER>.json` เก็บ OHLCV รายวันที่ปรับ split/ปันผลแล้ว (โหลดเฉพาะบริษัทที่สุ่มได้ในรอบนั้น)
- `prices/_INDEX.json` คือดัชนีเมือง (SPY)

ตัวเลือก: `--start 2014-01-01 --end 2025-12-31 --fx 35` (fx คืออัตราแปลง USD เป็นบาทที่เกมใช้)
รายชื่อหุ้น เซกเตอร์ และคำอธิบายภาษาไทยแก้ได้ที่ `scripts/universe.json`

> งบการเงินเป็น **ค่าประมาณ** เพราะ yfinance ให้ข้อมูลย้อนหลังแค่ราว 4 ปี ปีที่เก่ากว่านั้นสคริปต์จะประมาณย้อนจากแนวโน้มการเติบโตเอง

## โครงสร้าง

```
scripts/          fetch_data.py, universe.json
public/data/      ข้อมูลที่สคริปต์สร้าง
src/engine/       TS ล้วน + unit tests
  provider/       MarketDataProvider (interface), HistoricalProvider, SimulatedProvider
  MarketView.ts   มุมมองที่ล็อกตามวันในเกม (ดึงข้อมูลอนาคตไม่ได้)
  sampler.ts      สุ่มช่วงเวลาและบริษัทแบบเฉลี่ยตามเซกเตอร์
  portfolio.ts    ซื้อ/ขาย, ค่าธรรมเนียม 0.15%, ต้นทุนเฉลี่ย, กำไรที่รับรู้แล้ว
  indicators.ts, metrics.ts, health.ts, news.ts, anonDate.ts, disguise.ts
src/data/         ข้อมูลเซกเตอร์ สี และชื่ออำพราง
src/scene/        ฉาก 3D (R3F): เกาะ ย่าน ตึก instanced หอดัชนี กล้อง
src/ui/           HUD, แผงตรวจสอบบริษัท + กราฟ, พอร์ต, มินิแมป, หน้าเริ่ม/เฉลย
src/store/        Zustand game store + playback clock
```

## โหมดการเล่น

- **บทเรียน 8 บท**: เล่นช่วงตลาดจริงที่คัดมาแล้ว มีโค้ชบอกทีละขั้นและกรอบสีแดงชี้จุดที่ต้องกด จบแต่ละบทด้วยการตัดสินใจ (`src/data/tutorials.ts`)
- **Market Run**: เลือกได้ทั้งเงินก้อนเดียว (1–3 ปี) และออมรายเดือน DCA (3–5 ปี) ซึ่งมีวันเงินเดือนออก แผนลงทุนอัตโนมัติ และวัดผลด้วย XIRR/TWR
  - เกมหยุดเองเมื่อเกิดเหตุสำคัญ (Decision Point) ไม่เกินเดือนละครั้ง หลังเลือกจะเร่งเวลาไป 2–3 เดือน แล้วโชว์ "เกิดอะไรขึ้นต่อ"
  - ราว 25% ของรอบจะมีเหตุการณ์จริงซ่อนอยู่ เช่น COVID 2020, ตลาดหมี 2022, วิกฤตแบงก์ 2023 (`src/data/events.ts`) โดยเกมไม่บอกล่วงหน้า
  - โหมดท้าทายมีสถิติแยก: คุมขาดทุนไม่เกิน 15% / แต่ละเซกเตอร์ไม่เกิน 30% / ห้ามขาย 6 เดือนแรก / ซื้อได้เฉพาะวันเงินเดือนออก
- **Sandbox**: ตลาดจำลองแบบสุ่มที่ปรับความถี่ของวิกฤตสมมติได้ แชร์ลิงก์ `#sandbox=<seed>-<ความถี่>` ให้เพื่อนเล่นตลาดเดียวกันได้
- **ใบรายงานผล**: มีเกรด A+–F (ผลตอบแทน / ความเสี่ยง / การกระจาย / พฤติกรรม), จับจังหวะขายตอนตื่นตระหนกและไล่ซื้อยอดดอย, คำแนะนำภาษาไทย, ความสำเร็จ 15 อย่าง และสถิติดีที่สุด
- **ธนาคารสำรองและอาคารพิเศษ**: อยู่บนที่ว่างระหว่างย่านในเมืองหลัก ธนาคารใหญ่ขึ้นตามสัดส่วนเงินสดในพอร์ต ส่วนอาคารพิเศษ (ห้องสมุด ประภาคาร หอดูดาว สวนปันผล รูปปั้น หอเกียรติยศ) จะปรากฏเองเมื่อเรียนจบบทหรือได้ความสำเร็จที่กำหนด (`src/data/unlocks.ts`)
- **สภาพอากาศ** = อารมณ์ตลาด: ☀️ ขาขึ้น / ⛅ ทรงตัว / 🌧️ ขาลง / ⛈️ ร่วงแรง / 🌫️ ผันผวนสูง / ✨ คึกคักแบบฟองสบู่

## กราฟิก เสียง และการตั้งค่า (⚙️)

- **กราฟิก ✨ สวยงาม**: เงา, bloom (หน้าต่างและไฟถนนเรืองแสง ชัดสุดในธีมกลางคืน) และ vignette ถ้าเฟรมเรตต่ำกว่า ~30 FPS ต่อเนื่อง เกมจะลดเป็น ⚡ ประหยัด ให้เอง
- **ฉากเมือง**: ท้องฟ้าไล่สีตามสภาพอากาศ ทะเลและหาดรอบเกาะ ถนนมีเส้นจราจรและไฟถนน ลานกลางเมืองมีกระถางดอกไม้ ตึกมีหน้าต่างแยกบาน ล็อบบี้กระจก บัวคาด และหลังคา 3 แบบ (ถังน้ำ / ลานจอด ฮ.+เสาสัญญาณกะพริบ / ยอดแหลม) บ้านหลังคาจั่วเปิดไฟตอนกลางคืน ต้นสน+ต้นไม้พุ่ม
- **ตึกตามธุรกิจ** (`src/scene/sectorStyle.ts`): เทคโนโลยี = ตึกกระจกเรียว+ไฟ LED ฟ้า, การเงิน = ขั้นบันได+โดมทอง+เสาโรมัน, พลังงาน = ปล่องควัน+กังหันลมหมุนได้, สินค้าอุปโภค = ป้ายโฆษณา+กันสาด, สุขภาพ = กากบาทเขียว+ลาน ฮ., อุตสาหกรรม = เครน+หลังคาฟันเลื่อย, อสังหาฯ = ระเบียง+สวนดาดฟ้า (ความสูง สี และไฟหน้าต่างยังสื่อความหมายเดิม)
- **ชีวิตในเมือง**: รถ 7 แบบ (เก๋ง แฮทช์แบ็ก SUV กระบะ แท็กซี่ บัส รถขนของ) เว้นระยะไม่ชนกันและหยุดรอไฟแดงที่ 7 แยก (`src/scene/Traffic.tsx`) คนเดินแกว่งแขนขาทั้งรอบลาน ฟุตปาธ และในย่าน (มากขึ้นเมื่อตลาดดี) นก ผีเสื้อ (หลบตอนฝนตก/กลางคืน) ควันปล่องไฟ ต้นไม้โยก และหน้าต่างกะพริบเมื่อหุ้นวิ่ง ±5% ในวันเดียว
- **ผังเมือง**: ทุกย่านหันหน้าเข้าหาหอดัชนี (ตึก บ้าน สวน หมุนตามย่าน) ระหว่างลานกลางกับถนนวงแหวนเป็นสวนสาธารณะ (ไม่มีถนนซี่ล้อแล้ว รถวิ่งเฉพาะวงแหวน) ธนาคารอยู่ช่องหน้าที่กว้างที่สุด สวนปันผลแปลงใหญ่ขึ้น
- **ทางเดินเชื่อมทั้งเมือง** (`src/scene/Paths.tsx`): ทางเดินในสวนกลางเมือง (มีทางเดินวงกลม ม้านั่ง โคมไฟ) → ทางม้าลายข้ามถนนวงแหวนทุกแยก (คนรอข้ามตอนไฟวงแหวนแดง) → ถนนคนเดินเข้าย่าน → ทางเดินรอบขอบย่านต่อกับซอยในย่าน → ทางเชื่อมออกไปทางเดินเลียบชายฝั่ง (มีเสาไฟ) คนเดินสุ่มเส้นทางไปได้ทุกที่บนเครือข่ายนี้ ย่านยังแยกกันเหมือนเดิม
- **หอดัชนีและทะเล**: หอดัชนีมีฐานขั้นบันได สระน้ำล้อมรอบ ตัวหอ 3 ช่วงพร้อมแถบไฟแนวตั้ง (สว่างตามแนวโน้มดัชนี) มงกุฎทอง เพชรลอยหมุน และวงแหวน ทะเลมีคลื่นขึ้นลง (vertex shader) และคลื่นซัดเข้าฝั่ง
- **ธรรมชาติและรายละเอียด** (`src/scene/Nature.tsx`, `World.tsx`): ดอกไม้ป่า กอหญ้า ก้อนหิน ต้นมะพร้าว ร่มชายหาด หินริมฝั่ง เรือใบ บอลลูน แปลงว่างในย่านเป็นสวนเล็ก (บ่อน้ำ ม้านั่ง ต้นไม้) บ้านมีกรอบหน้าต่าง กระบะดอกไม้ ชานหน้าบ้าน รั้ว ทางเดิน ตู้จดหมาย น้ำพุหน้าธนาคารมีสายน้ำพุ่งและระลอกน้ำ (`Fountain.tsx`) อาคารพิเศษทุกหลังโมเดลละเอียดขึ้น ของตกแต่งใช้ Lambert material และโหมดประหยัดจะตัดดอกไม้/หญ้า/ผีเสื้อออก
- **เสียง**: สังเคราะห์ด้วย WebAudio ไม่ใช้ไฟล์ มีเสียงซื้อขาย เงินเข้า แจ้งเตือน ข่าวด่วน ฟ้าร้อง และฝน
- **เพลงพื้นหลัง**: ดนตรีสดใสแนวเกมสร้างเมือง สร้างสดด้วย WebAudio (`src/lib/music.ts`): คอร์ดเมเจอร์ คาลิมบา เบส กระดิ่ง และเชกเกอร์เบา ๆ ตอนฝนตกจะช้าลงและนุ่มลง แต่ยังคงคีย์สดใส เปิด/ปิดแยกจากเสียงเอฟเฟกต์ได้ที่ ⚙️
- **โมเดล .glb (ไม่บังคับ)**: วางไฟล์ CC0 เช่นจาก Kenney ไว้ที่ `public/models/` แล้วระบุใน `public/models/manifest.json` (ดู README ในโฟลเดอร์นั้น)

## วิธีอ่านเมือง

| สิ่งที่เห็น | ความหมาย |
|---|---|
| ความสูงของตึก | มูลค่าตลาด (log scale) |
| ความกว้างของตึก | รายได้ |
| ไฟหน้าต่าง | โมเมนตัม 20 วัน (สว่างคือขาขึ้น มืดคือขาลง) |
| สีตึก | มูลค่าเทียบกำไร (ฟ้าคือ P/E ต่ำ ส้มคือ P/E สูง เทาคือขาดทุน) |
| นั่งร้านสีส้ม | หนี้สูง หรือ EPS ลดลงเกิน 10% |
| ธงสีชมพูบนหลังคา | คุณถือหุ้นตัวนี้อยู่ |
| ความสูงของหอดัชนีกลางเมือง | ดัชนีเมืองเทียบกับวันเริ่มรอบ |

ปุ่มลัด: `Space` หยุด/เล่น · `1` `2` `3` ความเร็ว 1x/5x/20x · `Esc` ปิดแผง · `Home` กลับมุมกล้อง (ดูทั้งหมดได้ที่ปุ่ม `?` บนแถบด้านบน) · ชี้ที่ตัวเลข/คำศัพท์ (ⓘ) เพื่อดูคำอธิบาย · แผงบริษัทมีปุ่มซื้อ/ขายติดด้านล่างเสมอ · รายชื่อบริษัทเรียงตามย่าน/ขึ้นแรง/ลงแรง/ที่ถือได้

บนมือถือ (จอแคบกว่า 640px) แถบบนจะย่อเหลือแค่ส่วนที่จำเป็น แผงพอร์ตเริ่มแบบพับไว้ และข้อมูลบริษัทเปิดเป็นแผ่นเลื่อนขึ้นจากด้านล่าง
